## Nachbearbeitung auf diesem Computer

- Neben dem Anbieter der Nachbearbeitung steht jetzt, wo sie läuft: **Auf diesem Mac** (unter Windows und Linux **Auf diesem Computer**) oder **Cloud**. Ein Anbieter gilt als auf diesem Computer, wenn seine Adresse `localhost` oder eine Loopback-Adresse ist, etwa Ollama oder LM Studio über den Anbieter **Custom**; alles andere, auch ein Server in deinem Netz, gilt als Cloud.
- Läuft das Modell auf diesem Computer, lässt DanyWhere es laden, sobald du ein Diktat mit Nachbearbeitung beginnst. Ein lokaler Server entlädt ein Modell nach ein paar Minuten ohne Anfrage, und ein großes neu zu laden kann eine halbe Minute dauern; das geschieht jetzt, während du sprichst, nicht danach.

## Der Verlauf mit der Tastatur

- Der Bleistift neben einem Eintrag ist weg: Ein Klick in den Text öffnet ihn wie bisher zum Bearbeiten.
- Mit der Tastatur erreicht Tab den Eintrag, Eingabe oder Leertaste öffnen ihn zum Bearbeiten (unter macOS braucht Tab dafür womöglich die **Tastaturnavigation** in Systemeinstellungen → Tastatur). Endet das Bearbeiten mit der Tastatur, geht der Fokus zurück auf den Eintrag, sodass es von dort weitergeht.
