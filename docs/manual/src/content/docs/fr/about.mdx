DanyWhere est un logiciel libre et open source. Cette page raconte d'où il vient et qui il remercie, et où trouver son code source et signaler un problème.

## D'où vient DanyWhere

DanyWhere est né d'un fork de [Handy](https://github.com/cjpais/Handy), l'app open source de reconnaissance vocale de CJ Pais, et suit depuis son propre chemin, avec des profils, des raccourcis de fin, le post-traitement et un historique qui garde chaque version. Les fondations de Handy le portent toujours (reconnaissance vocale locale, détection d'activité vocale, raccourcis globaux, insertion de texte sur trois plateformes), et nous en sommes reconnaissants ; DanyWhere est un projet indépendant, et les créateurs de Handy n'y participent pas et n'en portent pas la responsabilité.

Si DanyWhere vous est utile, soutenez aussi Handy sur [handy.computer](https://handy.computer).

## Code source et problèmes

Le code source de DanyWhere se trouve sur GitHub, à l'adresse [github.com/yaccob/DanyWhere](https://github.com/yaccob/DanyWhere), avec chaque version à télécharger. Si quelque chose ne fonctionne pas comme ce manuel le décrit, ou s'il vous manque quelque chose, dites-le-nous dans les [issues](https://github.com/yaccob/DanyWhere/issues) du dépôt.

Si vous découvrez DanyWhere, commencez par [Une dictée du début à la fin](../how-it-works/dictation-from-start-to-end/).
