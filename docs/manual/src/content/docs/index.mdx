## Try it now

Once DanyWhere is set up, put the cursor in any text field, press <kbd>⌃ Space</kbd> on a Mac (<kbd>Ctrl+Space</kbd> on Windows, <kbd>Ctrl+Alt+Space</kbd> on Linux) and say a sentence. Press the same keys again, and your words appear where the cursor is. Everything else in this manual is about making that moment fit the way you write.

## Where to start

If you're new to DanyWhere, read [A dictation from start to end](how-it-works/dictation-from-start-to-end/) first. It walks through one dictation from the first key press to the done sound, and every later chapter builds on it. If you already dictate every day and want more out of the end of a dictation, go straight to [Start and end shortcuts](how-it-works/start-and-end-shortcuts/).

DanyWhere is based on [Handy](https://github.com/cjpais/Handy), the free, open-source speech-to-text app by CJ Pais and contributors, and is not affiliated with it.
