Mit DanyWhere musst du nicht schon vor dem Sprechen entscheiden, was mit deinen Worten geschehen soll. Du beginnst jedes Diktat gleich und wählst am Ende: Die Tasten, mit denen du aufhörst, sagen auch, ob ein Leerzeichen oder ein neuer Absatz folgt und ob eine Chatnachricht gleich abgeschickt wird. Mit einer weiteren Taste, vor dem Ende gedrückt, sagst du einem KI-Modell, was es mit dem Text tun soll. Dieses Kapitel zeigt die vier Listen von Tastenkombinationen dahinter, was eine neue Installation mitbringt und wie du eigene einrichtest.

## Vier Listen derselben Art

Unter **Grundeinstellungen › Allgemein** folgen vier Listen aufeinander:

- **Starttasten** starten eine Aufnahme, wenn du sie antippst. Sie läuft, bis eine Endtaste sie beendet.
- **Haltetasten** nehmen auf, solange du sie hältst. Das Loslassen beendet die Aufnahme so, wie der Eintrag es sagt.
- **Anweisungstasten** schalten eine laufende Aufnahme vom Text zur Anweisung: Was du danach sagst, sagt der Nachbearbeitung, was sie mit dem Text tun soll, etwa „übersetze das ins Polnische“. [Die gesprochene Anweisung](../spoken-instruction/) erklärt sie.
- **Endtasten** beenden eine laufende Aufnahme so, wie der Eintrag es sagt.

Eine Starttaste ist nur eine Tastenkombination. Halte-, Anweisungs- und Endtasten haben dieselben Teile, weiter unten beschrieben: einen Namen, eine Tastenkombination, **Anhängen** und **Kontext senden**.

Start- und Haltetasten belegt DanyWhere die ganze Zeit. Anweisungs- und Endtasten belegt es nur, solange eine Aufnahme läuft, so wie <kbd>Esc</kbd>. Deshalb kann <kbd>↩</kbd> ein Diktat beenden und <kbd>⇥</kbd> zur Anweisung schalten, ohne dir sonst in die Quere zu kommen: Den Rest der Zeit tun die Tasten, was sie immer tun.

## Was eine Tastenkombination tut

Was eine Tastenkombination tut, folgt aus den Listen, in denen sie steht. Dieselbe Tastenkombination darf in mehreren Listen stehen; innerhalb einer Liste dürfen keine zwei Einträge dieselbe haben.

| Die Tastenkombination ist … | Ohne Aufnahme | Während einer Aufnahme |
|---|---|---|
| eine Starttaste | Antippen startet eine Aufnahme, die weiterläuft. | Sie beendet die Aufnahme wie die Endtaste mit derselben Tastenkombination und tut nichts, wenn es keine solche gibt. |
| eine Haltetaste | Halten nimmt auf; das Loslassen beendet die Aufnahme mit den Werten dieses Eintrags. Kurzes Antippen tut nichts. | Wie bei einer Starttaste. |
| eine Start- und eine Haltetaste | Kurzes Antippen startet eine Aufnahme, die weiterläuft; Halten nimmt auf, bis du loslässt. | Wie bei einer Starttaste. |
| eine Anweisungstaste | Nichts: Die Taste geht an die App. | Sie schaltet zur Anweisung. |
| eine Endtaste | Nichts: Die Taste geht an die App. | Sie beendet die Aufnahme mit den Werten dieses Eintrags. |

Eine Anweisungstaste darf die Tastenkombination einer Start- oder Haltetaste haben: Ohne Aufnahme startet die Taste eine, während einer Aufnahme schaltet sie zur Anweisung. Die Tastenkombination einer Endtaste darf sie nicht haben, denn beide sind nur während einer Aufnahme belegt.

## Antippen, halten oder beides

DanyWhere unterscheidet Antippen und Halten daran, wie lange du die Tasten drückst. Eine Tastenkombination, die Start- und Haltetaste ist, kann beides. Auf dem Mac tippst du <kbd>⌃ Leertaste</kbd> an, sprichst, so lange du willst, und tippst sie wieder an; oder du hältst sie, während du sprichst, und lässt los, wenn du fertig bist.

Tippst du eine Haltetaste, die nicht auch Starttaste ist, nur kurz an, verwirft DanyWhere die Aufnahme: Nichts wird transkribiert, eingefügt oder behalten. Eine versehentlich gedrückte Taste bleibt so folgenlos. Die Listen sagen unter jedem Eintrag, was er tut: **Auch Haltetaste** unter einer Starttaste, und unter einer Haltetaste **Auch Starttaste: kurzes Antippen startet eine Aufnahme, die weiterläuft.** oder **Nur Haltetaste: kurzes Antippen tut nichts.**

Auch Anweisungstasten kennen beide Arten. Tippst du eine an, schickt eine Endtaste das Diktat ab. Hältst du sie, während du die Anweisung sprichst, schickt das Loslassen es ab.

## Woraus Halte-, Anweisungs- und Endtasten bestehen

Jeder Eintrag hat diese Teile:

- **Name:** So zeigt die Liste den Eintrag an. Eine Endtaste ohne eigenen Namen zeigt ihre Tastenkombination. Eine Halte- oder Anweisungstaste zeigt ihre Tastenkombination mit „gehalten“, etwa **⌃ Leertaste gehalten**, denn ihre Werte sagen, was beim Loslassen geschieht.
- **Die Tastenkombination.** Jeder Eintrag braucht eine.
- **Anhängen:** was nach dem Text kommt. Im Textfeld ist `\s` ein Leerzeichen, `\n` ein Zeilenumbruch und `\t` ein Tabulator; alles andere wird angehängt, wie es dasteht. Daneben kannst du einen Tastendruck wählen, etwa Enter, der gesendet wird, nachdem der Text eingefügt ist. Eine Zeile darunter sagt in Worten, was angehängt wird.
- **Kontext senden:** Frühere Diktate aus demselben Fenster gehen mit, damit das Modell weiß, worum es gerade geht. Das wirkt nur, wenn das Diktat nachbearbeitet wird.

Ob ein Diktat nachbearbeitet wird, entscheidet nicht der Eintrag. Das entscheidet **Nachbearbeitung** unter **Grundeinstellungen › Erweitert**, ab Werk auf **Mit Anweisungstaste**: Dann wird ein Diktat nachbearbeitet, wenn du während der Aufnahme eine Anweisungstaste drückst. [Die gesprochene Anweisung](../spoken-instruction/) zeigt alle drei Möglichkeiten.

## Die Tasten einer neuen Installation

<Tabs syncKey="os">
<TabItem label="macOS">

Auf dem Mac startet und hält dieselbe Tastenkombination, und die Endtasten folgen einer Regel:

- <kbd>⇧</kbd> (Shift) wählt die kleinere Variante: kein Leerzeichen statt eines Leerzeichens, eine Zeile statt eines Absatzes.
- <kbd>↩</kbd> (Return) schickt ab, wie beim Tippen: Es drückt nach dem Text Enter.
- <kbd>⌥</kbd> (Option) hält <kbd>↩</kbd> vom Abschicken ab: Es hängt stattdessen einen Absatz oder eine Zeile an.

| Liste | Tastenkombination | Name | Was nach dem Text kommt |
|---|---|---|---|
| **Starttasten** | <kbd>⌃ Leertaste</kbd> | | |
| **Haltetasten** | <kbd>⌃ Leertaste</kbd> | **⌃ Leertaste gehalten** | ein Leerzeichen |
| | <kbd>⌃⇧ Leertaste</kbd> | **⌃⇧ Leertaste gehalten** | nichts |
| **Anweisungstasten** | <kbd>⇥</kbd> (Tab) | **⇥ gehalten** | ein Leerzeichen |
| **Endtasten** | <kbd>⌃ Leertaste</kbd> | **Leerzeichen** | ein Leerzeichen |
| | <kbd>⌃⇧ Leertaste</kbd> | **Ohne Leerzeichen** | nichts |
| | <kbd>⌥↩</kbd> | **Absatz** | zwei Zeilenumbrüche |
| | <kbd>⌥⇧↩</kbd> | **Zeile** | ein Zeilenumbruch |
| | <kbd>↩</kbd> | **Enter senden** | ein Druck auf Enter |
| | <kbd>⇧↩</kbd> | **Shift-Enter senden** | ein Druck auf Shift+Enter |

Bei allen ist **Kontext senden** angehakt, sodass ein nachbearbeitetes Diktat sieht, was du vorher im selben Fenster geschrieben hast.

Im Alltag: Für einen längeren Text tippst du <kbd>⌃ Leertaste</kbd> zum Starten an und noch einmal zum Beenden; jedes Stück bekommt sein Leerzeichen und ist bereit für das nächste. Oder du hältst sie, während du sprichst. In einer E-Mail beendest du mit <kbd>⌥↩</kbd>, und der nächste Absatz steht bereit. Im Chat schickt <kbd>↩</kbd> die Nachricht ab, als hättest du sie getippt; tippst du vorher <kbd>⇥</kbd> an und sagst „etwas freundlicher“, wird sie zuerst überarbeitet.

<TabItem label="Windows">

## Eine Taste hinzufügen oder ändern

Alle vier Listen findest du unter **Grundeinstellungen › Allgemein**.

<Screenshot
  name="end-shortcuts"
  alt="Die Gruppe Endtasten unter Grundeinstellungen › Allgemein. Jede Endtaste ist ein Block mit ihrem Namen, ihrer Tastenkombination, dem Feld Anhängen mit einer Auswahl für den Tastendruck, einer Zeile, die sagt, was angehängt wird, und dem angehakten Kästchen Kontext senden. Zuerst kommen Leerzeichen mit der Tastenkombination der Starttaste, Ohne Leerzeichen mit der einer Haltetaste, und Absatz."
  caption="Die Endtasten unter Grundeinstellungen › Allgemein."
/>

Jede Liste hat ihren Knopf: **Starttaste hinzufügen**, **Haltetaste hinzufügen**, **Anweisungstaste hinzufügen** und **Endtaste hinzufügen**. Klick darauf und drück die gewünschte Tastenkombination; dann stellst du ein, was der Eintrag tut. Um eine Tastenkombination zu ändern, klick darauf und drück die neue. Das Papierkorb-Symbol daneben löscht einen Eintrag. Eine Start- oder Haltetaste bleibt immer, damit sich eine Aufnahme immer starten lässt, und eine Endtaste, damit sie sich immer beenden lässt. Anweisungstasten dürfen ganz fehlen.

Ein Profil kann von den Grundeinstellungen abweichen. Ändere auf der Seite **Allgemein** des Profils einen Eintrag einer der vier Listen, füge einen hinzu oder lösche einen, und nur dieser Eintrag gehört dann dem Profil allein. Alle anderen folgen weiter den Grundeinstellungen, auch deinen späteren Änderungen dort. Wie das bei jeder Einstellung funktioniert, zeigt [Grundeinstellungen und Profile](../defaults-and-profiles/).

## Rezept: eine Chatnachricht gleich abschicken

Im Chat willst du meist deine Nachricht sagen und sie abgeschickt haben, ohne zur Maus zu greifen. Eine Endtaste, die nach dem Text Enter drückt, macht genau das.

<Steps>

1. Öffne **Grundeinstellungen › Allgemein** und scroll zu **Endtasten**.

2. Klick auf **Endtaste hinzufügen** und drück die Tastenkombination, mit der du abschicken willst, zum Beispiel <kbd>Strg+Eingabe</kbd> unter Windows oder <kbd>⌘↩</kbd> auf dem Mac.

3. Lass unter **Anhängen** das Textfeld leer und wähl als Tastendruck **Eingabe** (<kbd>↩</kbd> auf dem Mac).

4. Hak **Kontext senden** an, wenn eine überarbeitete Nachricht sehen soll, was vorher gesagt wurde.

5. Gib ihr einen Namen, den du wiedererkennst, etwa `Senden`.

6. Probier es aus: Beginne in einem Chat ein Diktat, sprich deine Nachricht und beende mit der neuen Tastenkombination. Der Text erscheint und wird abgeschickt. Soll er vorher überarbeitet werden, tipp vor dem Beenden die Anweisungstaste an und sag, was geschehen soll, oder gar nichts.

</Steps>

:::tip
Auf dem Mac bringt eine neue Installation das schon mit: <kbd>↩</kbd> schickt die Nachricht ab. Tippst du vorher <kbd>⇥</kbd> an, wird sie zuerst überarbeitet.
:::

## Grenzen

:::caution[Linux]
Unter Linux kann DanyWhere eine Tastenkombination nicht nur für die Dauer einer Aufnahme belegen. Es belegt deshalb keine eigene Tastenkombination einer Endtaste und hat keine Anweisungstasten. Eine Aufnahme endet dort, wenn du eine Haltetaste loslässt oder eine Starttaste erneut antippst, deren Tastenkombination eine Endtaste hat; die letzte solche Endtaste lassen die Einstellungen nicht entfernen. Für das Rezept oben gibst du den Druck auf Enter deshalb einer Endtaste mit der Tastenkombination einer Starttaste oder einer Haltetaste. Um unter Linux nachzubearbeiten, stell **Nachbearbeitung** auf **Immer**, wenn du magst in einem eigenen Profil.
:::

**Auf einem Mac ohne Bedienungshilfen** kann DanyWhere keine Tasten drücken. Fährst du ohne die Berechtigung fort, lässt eine neue Installation die zwei Endtasten weg, die Enter oder Shift-Enter senden, sodass <kbd>↩</kbd> dort nichts beendet; <kbd>⌥↩</kbd> und <kbd>⌥⇧↩</kbd> beenden weiterhin mit einem Absatz oder einer Zeile. Ein unter **Anhängen** gewählter Tastendruck wird nicht gesendet.

**macOS selbst nutzt <kbd>⌃ Leertaste</kbd>**, um zwischen Eingabequellen zu wechseln, sobald du mehr als eine hast. Wechselst du so dein Tastaturlayout, schalte diesen Kurzbefehl in den Systemeinstellungen unter Tastatur › Tastaturkurzbefehle › Eingabequellen aus, oder gib DanyWhere andere Tastenkombinationen.
