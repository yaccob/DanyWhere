DanyWhere is free, open-source software. This page tells where it comes from and whom it thanks, and where you find its source code and report a problem.

## Where DanyWhere comes from

DanyWhere began as a fork of [Handy](https://github.com/cjpais/Handy), CJ Pais's open-source speech-to-text app, and has since gone its own way, with profiles, end shortcuts, post-processing and a History that keeps every version. Handy's groundwork still carries it (local speech recognition, voice detection, global shortcuts, inserting text on three platforms), and we are grateful for it; DanyWhere is an independent project, and Handy's makers are neither involved in it nor responsible for it.

If DanyWhere is useful to you, please support Handy too, at [handy.computer](https://handy.computer).

## Source code and problems

DanyWhere's source code is on GitHub, at [github.com/yaccob/DanyWhere](https://github.com/yaccob/DanyWhere), together with every release to download. If something doesn't work the way this manual describes, or you miss something, tell us in the repository's [issues](https://github.com/yaccob/DanyWhere/issues).

If you're new to DanyWhere, start with [A dictation from start to end](../how-it-works/dictation-from-start-to-end/).
